# Incident Automation Accelerator

A prototype demonstrating automated incident resolution and analytics for ERP/eCommerce systems.  
Designed to showcase enterprise-scale thinking, automation, and continuous improvement — aligned with the Nespresso CoE Expert role.

---

## 🚀 Features
- **Incident ingestion & tracking**: Mock ERP/eCommerce incidents stored in SQL/CSV.
- **Rule-based auto-resolution**: .NET Core API applies resolution logic and triggers automation scripts.
- **Automation scripts**: PowerShell, Shell, and SQL scripts simulate ERP/eCommerce fixes.
- **React dashboard**: Displays incidents, resolution status, MTTR metrics, and feedback loop.
- **Continuous improvement**: Analyst feedback captured to refine automation success.

---

## 🛠️ Tech Stack
- **Backend**: ASP.NET Core (.NET 7, C#)
- **Frontend**: React 18 + Axios
- **Database**: SQL/PostgreSQL (mock dataset)
- **Automation**: PowerShell, Shell, SQL scripts
- **Logging/Monitoring**: Serilog, Swagger UI for API testing
