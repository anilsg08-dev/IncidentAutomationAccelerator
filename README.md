# Incident Automation Accelerator

A prototype demonstrating automated incident resolution and analytics for ERP/eCommerce systems.
Built with **.NET Core**, **React**, and automation scripts (PowerShell, Shell, SQL).

## Features
- Incident ingestion and tracking
- Rule-based auto-resolution
- Automation scripts for ERP/eCommerce fixes
- React dashboard with MTTR metrics
- Feedback loop for continuous improvement

## Tech Stack
- Backend: .NET Core (C#)
- Frontend: React JS
- Database: SQL/PostgreSQL (mock dataset)
- Automation: PowerShell, Shell, SQL scripts
